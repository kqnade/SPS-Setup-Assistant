SPS2 Setup Assistant — kqnade fork

非公式プレリリース 1.1.2-kqnade.1

LumaKroma/SPS2-Setup-Assistant の1.1.1を基にしたforkです。VRCFury 1.1452.0で観測したSPS3のAuto・Legacy Supportメニュー名を認識します。SPS3全機能の対応を保証するものではありません。

このforkでのUnityコンパイル・EditModeテスト・VRChat動作・VCC／ALCOM実導入は未検証です。導入前に、プロジェクト全体をプロジェクト外へバックアップしてください。

下のボタンからリポジトリを登録し、VCC／ALCOMでプレリリースパッケージの表示を有効にしてください。アバタープロジェクトで SPS2 Setup Assistant (kqnade prerelease) の 1.1.2-kqnade.1 を選択します。

上流と同じパッケージIDを使います。上流のリポジトリも登録している場合は、バージョンを自動選択に任せず、このforkのバージョンを明示的に選んでください。

変更内容・制限はRelease、旧Assets版の削除対象と復元手順は移行の注意事項を確認してください。
